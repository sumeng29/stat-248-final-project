# stat-248-final-project

This is the repo for my STAT248 Final Project

# Question

Do daily S&P 500 returns show volatility clustering, and does modeling time-varying volatility describe market risk better than treating volatility as constant?

# Files
- `248 final project.ipynb` — full analysis notebook
- `SP500.csv` — raw daily S&P 500 closing prices from FRED
  (https://fred.stlouisfed.org/series/SP500), Apr 2016 – Apr 2026
- `SP500_clean.csv` — log returns generated by the notebook
